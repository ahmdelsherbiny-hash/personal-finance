# 💰 محفظتي | Personal Finance Portal

بوابة شخصية ذكية وسريعة لتسجيل وتتبع المصاريف والدخل والتحليلات المالية، جاهزة للتشغيل والنشر المباشر على **GitHub Pages** بنسبة 100% وبدون الحاجة لأي خادم (Serverless / Static Web App).

---

## ✨ المميزات الرئيسية

- ⚡ **بسيطة وسريعة (Simple & Fast):** واجهة مستخدم نظيفة وعصرية متوافقة مع الهواتف والشاشات الكبيرة مع دعم كامل للوضع الليلي والفاتح (Dark / Light Mode).
- 📊 **تحليلات ورسوم بيانية تفاعلية (Informative):**
  - كروت ملخص الرصيد الصافي، إجمالي الدخل، إجمالي المصاريف، ومعدل الادخار.
  - رسم بياني دائري لتوزيع المصاريف حسب الفئات بنسب مئوية.
  - رسم بياني لمعدل الصرف اليومي عبر أيام الشهر.
  - رسم بياني لمقارنة الدخل مقابل المصروف لآخر 6 أشهر.
  - توزيع المدفوعات حسب وسيلة الدفع (كاش، فيزا، محفظة إلكترونية، تحويل بنكي).
- 🎯 **إدارة الميزانية الذكية (Budgets):** تحديد سقف شهري للمصاريف مع شريط تقدم وتنبيهات ملونة عند الاقتراب من تجاوزه.
- 🔍 **بحث وفلترة دقيقة:** فلترة حسب الشهر، النوع (دخل / مصروف)، الفئة، وبحث نصي في الوصف والملاحظات.
- 🔒 **خصوصية وأمان 100%:** جميع بياناتك مخزنة محلياً على متصفحك الخاص (`localStorage`) ولا يتم إرسال أي معلومة لأي خادم خارجي.
- 💾 **تصدير واستعادة البيانات:**
  - تصدير كملف **CSV** متوافق مع Excel واللغة العربية (UTF-8 with BOM).
  - تحميل نسخة احتياطية كاملة بصيغة **JSON**.
  - إمكانية استعادة البيانات في أي وقت أو نقلها لجهاز آخر.

## 🚀 كيفية النشر على GitHub Pages (خطوة بخطوة)

المشروع مصمم ليعمل مباشرة كـ Static Site على GitHub Pages:

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. ادخل إلى حسابك على [GitHub](https://github.com) واضغط **New Repository**.
2. سمّ المستودع مثلاً: `personal-finance` أو `my-wallet`.
3. اجعله **Public** واضغط **Create repository**.

### الخطوة 2: رفع ملفات المشروع
افتح الـ Terminal في مجلد المشروع وقم بتنفيذ الأوامر التالية:

```bash
git init
git add .
git commit -m "Initial commit: Personal Finance Portal"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<REPO_NAME>.git
git push -u origin main
```
*(استبدل `<YOUR_GITHUB_USERNAME>` باسم حسابك و `<REPO_NAME>` باسم المستودع)*

### الخطوة 3: تفعيل GitHub Pages
1. ادخل إلى صفحة المستودع على GitHub.
2. اذهب إلى **Settings** ⚙️ ثم اختر من القائمة الجانبية **Pages**.
3. في قسم **Build and deployment**:
   - **Source**: اختر **Deploy from a branch**.
   - **Branch**: اختر `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. انتظر دقيقة أو دقيقتين وقم بتحديث الصفحة، ستظهر لك رسالة:
   `Your site is live at https://<username>.github.io/<repo>/`

مبروك! بوابتك المالية أصبحت متاحة أونلاين على هاتفك وحاسوبك في أي وقت! 🎉

## 🛠️ التقنيات المستخدمة
- **HTML5 & Modern CSS3**: تصميم متجاوب بدون أي مكتبات ثقيلة، يدعم RTL والـ Custom Properties.
- **Vanilla JavaScript**: إدارة الحالة (State)، التخزين المحلي، وحساب الإحصائيات.
- **Chart.js**: لإنشاء رسوم بيانية تفاعلية سلسة.
- **Lucide Icons**: أيقونات عصرية خفيفة ونقية.
- **Google Fonts (Cairo & Plus Jakarta Sans)**: خطوط عربية ولاتينية مقروءة وواضحة.
